# 《物化》 · Butterfly Dream

**他去梦里唤醒她；梦却先唤醒了他。**

*两千四百年前，庄周在蒙地的柳树下睡着了，梦见自己变成一只蝴蝶。*

*两千四百年后，有人把这个梦，做成了一台机器。*

## 📖 故事简介

2050年，春。南方城市郊外的蜃楼计划总部，第十四层住着三十七位“持续意识沉默症”病人：脑干完好，心跳平稳，只是那个通常被称为“本人”的东西不知去向。像一栋所有窗户都亮着灯的房子，挨个敲门，没有人应。

首席工程师陆离在这里主持一项近乎莽撞的技术——**梦桥**：把结构完整的梦境流注回他们的大脑。既然叫不应，就走进去。

他的妻子躺在最尽头的那间病房里。昏迷第九十七天。

伦理委员会三次驳回他的申请之后，某个下雨的凌晨两点，陆离用首席权限打开了那台不该用于治疗的零号舱。他只想看一眼，她在哪儿。

他看见了她的梦。梦里有他从没对任何人讲过的走廊——绿色墙裙，水磨石地面，他十一岁那年的夏天；有玻璃倒影里那张瘦下去的脸。而玻璃里的她，隔着两层世界，望进了他的眼睛最深处，笑了一下。

从这一夜起，现实开始漏水：

二十九位互不相识的病人，反复梦见同一座悬在浓雾里、桥下无水的白桥；一千三百个散落在地球两端的家庭，流传着同一句没头没尾的家训——**睡觉的时候，要攥着它**；死去三年的前任首席，档案深处留着一条条越来越短的工作笔记：

“今日见弧。”“弧度偏北。”“雾薄了。”

最后一条写于坠楼前的深夜：“又清晰了。”

所有线索指向同一个方向——

**这座桥，不是任何人画出来的。它是被送进来的。**

而要知道是谁在发送，就得有人顺着桥，往上走。
